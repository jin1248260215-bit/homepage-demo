如何读取这些数字

Codex：图中“剩余”是相应使用窗口的额度百分比，不是固定的 Token 数量，也不是某一次对话的上下文长度。不同任务的消耗可能不同。

快照时间：Codex 数据来自最近一次已同步快照。点击刷新只会加载最新已同步的数据，不会直接读取你的 Codex 账号。快照超过 30 分钟会提醒；窗口重置时间已过时，需等待新快照。

DeepSeek：环图展示赠送余额与充值余额的构成，不表示“已用／总量”。可用 Token 数受模型、输入输出长度及缓存命中等影响，因此这里保留官方返回的金额。

可按需刷新 DeepSeek 余额；页面会标注实际更新时间。灰色空环表示尚无可展示的数据，不代表额度为零。
